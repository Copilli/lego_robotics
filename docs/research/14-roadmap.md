# 14 — Evidence-driven roadmap

All phases are **PLANNED**; none should be reported complete based on this repository's current evidence.

1. **Research & Preservation** — repeat inventory on a host with legacy apps; document app versions, formats, content relationships, and protocol sources.
2. **EV3 Connectivity** — prove a real-brick connection on iPad first, then Android; read battery/ports and safely run/stop a motor.
3. **Programming Environment** — choose a runtime and block editor after transport constraints are known; validate touch interactions on a tablet.
4. **Original Content Import** — implement a copy-first importer for one verified source and preserve asset provenance.
5. **Tablet Experience** — add responsive lesson/program split view, local projects, and offline content.
6. **Teacher Tools** — define and implement teacher-facing objectives, notes, and assessment from educator feedback.
7. **Community Lessons** — establish a schema, accessibility, licensing, and review process before sharing content.

## Current blockers

- Official applications and source assets are absent in the available sandbox.
- Protocol documentation and external technical sources could not be fetched during this pass.
- No physical EV3 brick, iPad, Android tablet, or desktop transport test is available.

Advance a phase only when its evidence and exit criteria are recorded; preserve UNKNOWN, UNTESTED, and unsupported states in the compatibility matrix.
