# Research and preservation evidence

## Current implementation

See [development](../development.md), [content and conversion limits](../classroom-content.md), [manual hardware validation](../manual-connection-validation.md) and the [content acceptance checklist](../CONTENT_CHECKLIST.md). The application lives in `src/`, with import/preservation scripts in `scripts/`. Physical EV3 and iPad connectivity must not be inferred from code or simulated tests.

## Evidence boundaries

The initial Linux discovery (2026-10-03), Windows inspection (2026-10-04/05) and later implementation/preservation records describe different dated observations. UNKNOWN means insufficient evidence, not absence; UNTESTED means behavior was not exercised. Recovered research documents retain historical proposals and limits, which may have been superseded by main.
